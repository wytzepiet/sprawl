Sprawl, routed

The town builds itself. Houses spring up and want things, and when nobody makes a thing, someone opens a place that does.

You draw the streets. Trucks run each one end to end and serve everything beside it.

Each week brings a truck and one pick. A house that waits too long shrinks.
